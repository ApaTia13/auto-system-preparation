# ⚙️ Auto System Preparation

Интерактивный скрипт для базовой начальной настройки (bootstrap) Linux-серверов с поддержкой различных дистрибутивов (Debian, Ubuntu, Astra Linux, RedOS, ALT Linux, CentOS, RHEL).

## 🚀 Быстрый старт

```bash
curl -fsSLo /tmp/autosys.sh https://raw.githubusercontent.com/ApaTia13/auto-system-preparation/refs/heads/main/autosys.sh && sudo bash /tmp/autosys.sh
```

Скрипт интерактивный и не работает через `curl | bash` (защита `require_tty`), поэтому сначала скачивается во временную папку, а затем запускается.

**Как это работает:**
1. Автоматически определяет операционную систему и выбирает правильный пакетный менеджер.
2. В интерактивном режиме запрашивает имя пользователя, публичный SSH-ключ и (опционально) пароль.
3. Обновляет систему, устанавливает базовые пакеты и настраивает безопасный SSH-доступ с возможностью автоотката при ошибке.

---

## 🛡️ Что делает скрипт

* **Мультиплатформенность**: Корректно работает с семействами Debian, RHEL и ALT Linux, используя их нативные инструменты (`apt`, `dnf`/`yum`).
* **SSH**: Настройка входа только по ключу, отключение парольной аутентификации, смена порта, `MaxAuthTries 3`. Использует современные drop-in файлы (`sshd_config.d`) с надежным механизмом отката при любой ошибке.
* **Пользователь**: Создание пользователя, безопасное добавление в группу `sudo` или `wheel`, опциональная установка пароля со строгой валидацией сложности.
* **Обновления**: Обновление пакетной базы системы и установка дополнительных пакетов по запросу пользователя.
* **Безопасность**: Криптографическая валидация SSH-ключа через `ssh-keygen`, проверка сетевого подключения и DNS, автоматическая настройка контекстов и портов SELinux (если он активен).

---

## ⚙️ Управление

Повторный запуск той же команды (без аргументов) открывает интерактивное меню, где можно:
1. Обновить SSH-ключ для существующего пользователя.
2. Сменить порт SSH (с полной проверкой и откатом при ошибке).
3. Выполнить полную настройку заново.
4. Выйти.

## 🚨 Troubleshooting (Решение проблем)

### Потерял доступ к SSH
1. Зайдите в VNC/KVM-консоль вашего хостинг-провайдера и авторизуйтесь локально.
2. Временно включите вход по паролю, отредактировав конфигурацию:
   ```bash
   # Если используется drop-in файл (современные ОС):
   sed -i 's/^PasswordAuthentication no/PasswordAuthentication yes/' /etc/ssh/sshd_config.d/00-autosys.conf
   # ИЛИ для старых ОС, где настройки в основном файле:
   sed -i 's/^PasswordAuthentication no/PasswordAuthentication yes/' /etc/ssh/sshd_config
   systemctl restart ssh
   ```
3. Войдите по паролю, исправьте настройки (например, добавьте верный ключ через меню скрипта) и снова отключите пароли.

### Скрипт выдает ошибку "скрипту нужен интерактивный терминал"
Вы пытаетесь запустить его через конвейер (`curl ... | bash`). Скрипт блокирует такой запуск для предотвращения зависаний при запросе данных. Используйте команду из раздела "Быстрый старт", которая сначала сохраняет файл, а затем запускает его.
